# Warning Capsule Safety Command Center

Dashboard prototype untuk pitch business plan **Warning Capsule**. Project ini dibuat dengan Next.js, Tailwind CSS, Recharts, Framer Motion, dan React Three Fiber.

## Fitur

1. **Safety Dashboard Utama**
   - Safety status
   - Battery level
   - BLE connection
   - Safe zone status
   - Guardian online
   - Emergency response metrics
   - Device health performance
   - Activity & safety timeline

2. **SOS Interactive Simulator**
   - Simulasi pull-pin/SOS
   - Mode normal internet, weak internet, dan false alarm
   - Emergency flow timeline
   - Response time chart
   - Guardian alert preview
   - Interactive 3D Structural Explorer

3. **Kustomisasi Guardian & Device**
   - Profil pengguna
   - Registrasi kode unik device
   - Kontak emergency guardian
   - Safe zone configuration
   - Privacy & consent rules

4. **Interactive 3D Structural Explorer**
   - Model 3D Warning Capsule berbasis primitive geometry, tanpa file GLB eksternal
   - Bisa diputar dengan drag
   - Bisa zoom dengan scroll
   - Bisa collapse/explode layers
   - Klik layer untuk melihat detail komponen
